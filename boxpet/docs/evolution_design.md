## 一、进化路线总览

```
        孵化               LV2+2天            LV3+5天            LV4+10天          60天
 [蛋形态期] ────→ [幼生期 LV1] ────→ [成长期 LV2] ────→ [成熟期 LV3] ────→ [完全体 LV4/5] ────→ [老年]
   4种蛋            3分支形态          3分支形态           3分支形态           3分支形态            沿用现外观
   随机1/4          力|魔|速           力|魔|速            力|魔|速            力|魔|速             寿终机制不变
```

- 形态总数：**4（蛋）+ 3×4（阶段分支）= 16 种静态形态 + 老年沿用 1 种**
- 每次进化（孵化 / 升到 LV2 / LV3 / LV4）都判定**分支 + 品质**，播放 3~4s 进化光效后定格新形态
- 等级继续沿用现有经验曲线（exp_to_next = 50×L^1.5，上限 30 级）：
  LV2/3/4 是进化门槛，LV5 之后只解锁玩法（零食/识字/音乐/相亲），外观停在完全体

### 阶段 ↔ 现有 Stage 枚举映射

| 新阶段 | Stage 枚举 | 进入条件（双门槛） |
| :--- | :--- | :--- |
| 蛋形态期 | `Stage::Egg`（沿用） | 新蛋/重生 |
| 幼生期 | `Stage::Baby`（沿用） | 孵化（沿用现有孵化天数） |
| 成长期 | `Stage::Juvenile`（沿用） | **LV≥2 且 日龄≥2 天** |
| 成熟期 | `Stage::Adult`（沿用） | **LV≥3 且 日龄≥5 天** |
| 完全体 | `Stage::Ultimate`（**新增**） | **LV≥4 且 日龄≥10 天** |
| 老年 | `Stage::Senior`（沿用） | 日龄≥60 天（完全体后，寿命/死亡机制不变） |

- 双门槛语义：等级、日龄**都满足**才进化；不满足则每 tick 复查，条件齐的瞬间立即进化（不吃亏也不速刷）
- 蛋期不可被条件跳过：孵化规则不变

## 二、分支判定与品质档位

### 分支（决定外观形态，判定时三选一）

```
进化方向 = argmax(power, magic, speed)
平局优先级：power > magic > speed
全 0（极端情况）→ 保底力量型
```

### 品质（决定华丽程度，判定时锁定本阶段档位）

| 档位 | 条件（三维之和） | 视觉表现（不新增素材） |
| :--- | :--- | :--- |
| 普通 | 总值 < 90 | 无特效 |
| 优秀 | 90 ≤ 总值 ≤ 150 | 2 颗闪烁星光粒子（2×2px 白/黄，绕宠物缓慢环绕） |
| 华丽 | 总值 > 150 | 白色呼吸光晕（复用进化光效 halo 样式）+ 4 颗星光粒子 |

- 品质在**每次进化判定时**重新计算并锁定，下一次进化可升档（不可降档后回看——以当前阶段判定为准）
- 品质写入 NVS，重启/深睡补跳后保持

### 属性成长联动（写入与读取路径，溢出 5:1 转经验沿用 M12 `add_growth`）

| 行为 | 属性收益 |
| :--- | :--- |
| 喂主食（高蛋白正餐） | power +2 |
| 教育（认字/算术/计数器/阅读/节奏） | magic +2 |
| 运动玩耍（丢球/自由玩） | speed +2 |
| 零食 | 三项各 +1（小奖励） |
| 高级料理/最爱食物 | power+1、magic+1 |

## 四、闲置玩耍动画系统设计

### 触发与中断

- 触发：宠物 `IDLE`（清醒、非生病/抑郁/睡觉）+ 无按键 **≥10s**（常量 `kIdlePlayDelayMs` 可调）
- 播放：循环直到任意按键；**按键立即中断**（现有 `on_key` 已重置空闲计时，扩展为同时取消玩耍态、清道具）
- 与现有系统关系：**替换**现有"随机小动作"（8~16s 单次 Happy/漫步/跳跃），漫步与跳跃保留为玩耍子动作

### 三种玩耍（每轮随机选一，持续 3~6s，可连续多轮）

| 玩耍 | 演出 | 阶段差异 |
| :--- | :--- | :--- |
| 蹦跳 | 正弦大跳 ×2~3 次 + happy 帧 | 幼生幅度小频率高；成熟/完全体幅度大更沉稳 |
| 追蝴蝶 | 蝴蝶道具(10×8)沿 S 形路径飞，宠物漫步跟随，追上时 happy 一声 | 蝴蝶速度随阶段加快（幼生慢好追，完全体灵活） |
| 玩球 | 球道具(8×8)在宠物前弹跳，宠物小跳顶球，球越弹越高 | 幼生只看；成长起会顶球 |

- 实现：ui_main 10Hz tick 驱动的状态机（`IDLE_WAIT → PLAYING(kind) →…`），全部走现有 animator/漫步位移通道，非阻塞
- 新增道具精灵 2 枚（蝴蝶/球，共约 72B），玩家交互后隐藏

## 五、资源规划（产出物 3）

### Flash 占用估算

精灵格式：48×48 4bpp = **1152B/帧**（沿用现有 16 色全局调色板，无独立调色板开销）

| 类别 | 数量 | 字节 |
| :--- | ---: | ---: |
| 蛋 idle ×4 | 4 | 4.5KB |
| 幼生/成长/成熟/完全体 idle | 12 | 13.8KB |
| 动作帧（eat/happy/zzz/sick/scold ×12 形态，姿势模板换色复用） | 60 | 69.1KB |
| 老年及死亡帧 | 沿用现有 | 0 |
| 道具（蝴蝶 10×8 / 球 8×8 4bpp） | 2 | ≈0.1KB |
| **合计新增** | **≈78 帧** | **≈87.5KB** |

- 被替换清理：旧 Baby/Child/Teen 单一外观 idle + 动作帧约 30 帧（≈34.5KB），**净增 ≈53KB**
- 现状：固件 1.84MB / app 分区 4MB（余量 2.3MB）→ 净增约 2%，无压力
- 生成方式：`tools/sprite_gen2.py` 程序化绘制（16 个形态函数 × 换色参数），无需外部美术素材

### RAM 占用

- 品质光效：2~5 个 2×2px `lv_obj` 粒子 + 1 个光晕对象（仅华丽档），复用现有星空/进化光效实现方式，≈0
- 玩耍道具：2 个小 canvas（10×8 / 8×8 RGB565 ≈ 0.3KB，走 PSRAM 同现有画布模式）
- NVS：PetState 增 `evo_branch`/`evo_quality` 等 <16B（整体 blob 存取沿用，旧存档一次性作废重开）

## 七、属性提升指南（数值全部来自 pet.cpp / pet_def.h 实现，与代码一一对应）

### 7.1 五大状态属性（0~100，实时显示在状态页）

| 属性 | 提升途径 | 降低途径 |
| :--- | :--- | :--- |
| **饱食** | 喂食：主食 +30、零食 +10、高级料 +50、最爱 +40（腐败食 −10） | 自然衰减 −1/30分钟；睡眠中减半；排泄触发时连带下降 |
| **心情** | 喂食：主食 +2、零食 +10、高级料 +15、最爱 +25；抚摸 +3；玩耍：丢球 +8、节奏 +20（失败也 +30%）、自由玩 +5；教育结束 全对 +5；生日/访客/安慰事件 +10~15 | 自然衰减 −1/45分钟；饿肚子（饱食=0）−5/小时；腐败食 −20；吃撑/被拒等 −3；噩梦不理 −10；商人被骗 −10 |
| **精力** | **睡觉（唯一恢复途径）**：+4/分钟（生病时减半），0→100 约 25 分钟；生日直接回满 | 清醒自然消耗 −0.15/分钟；玩耍扣：丢球 −5、节奏 −15、自由玩 −3；教育扣：认字/算术 −8、音乐 −10、自由阅 −3、计数器 −1 |
| **卫生** | **洗澡（唯一恢复途径）**：直接回满 100（动画 1.6s）；生日直接回满 | 自然衰减 −1/60分钟；便便每坨 −15；下雨"打伞出去" −20 |
| **健康** | 药品：退烧药 +30（同时解除生病）、维生素 +10（另送 24h 免疫）、特效药回满并解除一切 debuff；**睡饱/喂饱**（饥饿=0 时健康持续掉，反之不掉）；生日直接回满 | 饥饿=0 时 −2/小时；生病状态持续；health=0 进入濒死，72 宠物小时后死亡 |

**状态属性联动规则**（低于 60 主界面有表情帧+四角图标提醒）：
- 卫生 ≤20 时每小时 30% 概率生病 → 喂药治
- 心情 ≤10 进入抑郁 → 抚摸 5 次治愈（治愈 +20 心情）；抑郁 1 宠物日未解 → 离家出走事件
- 饱食 ≥95 拒绝喂食；零食连喂 3 次 → 吃撑 debuff（之后喂东西 30% 生病）
- 起床需精力 ≥60；玩耍需精力 ≥15；教育需精力 ≥20

### 7.2 智力 / 亲密度（0~999，不衰减）

| 属性 | 提升途径 |
| :--- | :--- |
| **智力** | 教育：认字/算术 +3/全对题、音乐 +5/题、自由阅 +1、计数器 +1；玩耍：节奏全对 +1；喂食：高级料 +1；**隔代遗传**：宝宝出生继承 10 + 父母智力加成 |
| **亲密度** | 喂食：最爱 +5；玩耍：节奏全对 +（bond_gain）等；离家出走没追回 −50 |

### 7.3 等级 / 经验（上限 30 级，升级曲线 50×L^1.5）

经验来源：喂食 +5、玩耍 +10、教育 +15、特殊事件 +20、繁育 +50；**进化分支值溢出 5:1 转经验**（刷不动上限但成长不浪费）。

| 等级 | 升级所需经验（累计需求见 exp_to_next） | 解锁 |
| ---: | --- | :--- |
| LV1→2 | 50 | 零食（LV2） |
| LV2→3 | 141 | 认字（LV3） |
| LV3→4 | 259 | 数学、音乐（LV5）——**LV3+5 天 → 进化成熟期** |
| LV4→5 | 447 | **LV4+10 天 → 进化完全体** |
| LV5→15 | 逐级递增（50×L^1.5） | 相亲繁育（LV15） |

注意：**等级只到 LV4 就触发最终进化**，LV5 之后升级只用于解锁玩法（零食/教育课程/相亲），外观停在完全体。

### 7.4 进化分支值（力量/魔法/速度 0~100，决定进化方向与品质）

| 行为 | 力量 | 魔法 | 速度 |
| :--- | ---: | ---: | ---: |
| 喂主食（高蛋白正餐） | **+2** | | |
| 喂零食 | +1 | +1 | +1 |
| 喂高级料 / 最爱 | +1 | +1 | |
| 教育（认字/算术/音乐/自由阅/计数器） | | **+2** | |
| 玩耍：节奏 | | **+2** | |
| 玩耍：丢球 / 自由玩（运动类） | | | **+2** |

- 每次进化（LV2/LV3/LV4 达成时）重判分支：取三值最大，平局 力>魔>速，全 0 保底力量
- 品质=三维之和：<90 普通 / 90~150 优秀 / >150 华丽（进化时定档，下次进化可升档）
- 想控制进化方向：在下次进化前重点喂主食（力）或玩教育/节奏（魔）或玩丢球/自由玩（速）

### 7.5 特殊事件收益（随机弹窗，限时选择）

| 事件 | 正确选择收益 | 代价/惩罚 |
| :--- | :--- | :--- |

| 下雨 | 打伞出去：心情 +15 | 卫生 −20 |

### 7.6 快速养成路线建议

1. **白天**：喂主食（力量）→ 教育/节奏（魔法）→ 丢球（速度），按想要的进化方向分配
2. **卫生掉到 60 以下图标亮起就洗澡**；便便及时清（−15 卫生/坨）
3. **晚上到点睡觉**：精力是硬通货（玩耍/教育都扣它），睡满 100 自动醒
4. **升级前攒够分支值**：临近 LV2/3/4 时狂喂对应食物/玩对应游戏，直接决定下一形态的分支和品质档
5. **别错过事件弹窗**：访客/流星/商人的稀有食物是免费的高级料与最爱，生日更是全属性回满
